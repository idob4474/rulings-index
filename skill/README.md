# מנתח פסקי דין לסטודנטים למשפטים

**[הורדת הסקיל, ruling-analyzer.zip](https://github.com/idob4474/rulings-index/releases/download/skills/ruling-analyzer.zip)**

סקיל ל-Claude שמנתח פסק דין ישראלי ומציג אותו בצ'אט ככרטיס לימוד, עם מראה מקום לכל טענה שנבדק מול הנוסח המלא.

## התקנה

1. ב-Claude נכנסים ל-Settings ואז ל-Capabilities, ומפעילים את Create and edit files.
2. מורידים את הקובץ מהקישור למעלה, ולא פותחים אותו.
3. נכנסים ל-Customize ואז ל-Skills, לוחצים על +, אחר כך על Create skill ואז על Upload a skill, ובוחרים את הקובץ.

משתמשי Claude Code מתקינים עם `/plugin marketplace add idob4474/rulings-index` ואחר כך `/plugin install ruling-analyzer@halachot-skills`.
