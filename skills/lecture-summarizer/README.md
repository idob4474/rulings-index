# מסכם הרצאה למשפטים

סקיל ל-Claude שהופך תמלול הרצאה לכרטיס לימוד בעיצוב של מנתח פסקי הדין. לפני הסיכום הסקיל מנקה את התמלול, כלומר מאחד שמות ומונחים משובשים לפי הסילבוס ומאמת מספרי הליכים מול האינדקס. כל מה שלא ברור מסומן "לאימות מול המקור".

## התקנה

מורידים את [lecture-summarizer.zip](https://github.com/idob4474/rulings-index/releases/download/skills/lecture-summarizer.zip) ומעלים ב-Customize, ואז Skills, ואז Upload a skill. ההתקנה המלאה מתוארת ב-[README הראשי](../../README.md). הסקיל מציג את הכרטיס דרך `ruling-analyzer`, ולכן צריך להתקין גם אותו.

## שימוש

מצרפים את תמלול ההרצאה וכותבים ״סכם את ההרצאה״. כדאי לצרף גם את הסילבוס, כי הוא משפר את תיקון השמות.

## מה לא עושה

הסקיל מסכם רק מה שנאמר בהרצאה. הוא לא מוסיף הלכות או סעיפים מעצמו, והסיכום אינו תחליף לקריאת חובה.
